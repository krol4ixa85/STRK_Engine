  next_unlock_date       ближайший разлок ≤90 дней
  next_unlock_size_strk  в STRK
  next_unlock_size_usd   размер × current_price
  next_unlock_pct_circ   next_unlock_strk / circulating_supply × 100
  daily_emission_strk    (unlocks_30d + inflation_30d) / 30
  daily_emission_usd     daily_emission_strk × current_price
  monthly_emission_usd   daily_emission_usd × 30

  · Если разлоков в ≤90 дней нет — печатать «none in 90d», не «нет данных»
  · Эмиссия 127M STRK/мес × $0.026 = $3.3M/мес продающего давления —
    это не «маленькая», это существенная база для сравнения с TVL/vol
  · unlock_pressure (порог MUST #12) = next_unlock_$ × CEX_share /
    median_daily_volume_$. CEX_share по умолчанию 0.5 (эмпирика).

СТРОКА В ОТЧЁТЕ:
  UNLOCKS: next $X @ DD.MM (N.NN% circ) · daily emission $Y ·
           quarterly dilution vs TVL Z% · unlock_pressure=<LOW|MED|HIGH>

ЛОВУШКИ:
  ⛔ «Разлок = дамп» — маршрут разлока определяет класс.
     unlock → stake        = LOCK (нейтрально, снимает с рынка)
     unlock → bridge L1→L2 = NEUTRAL (перемещение)
     unlock → CEX          = SELL_RISK (продающее давление)
     Требуется PLAYBOOK_FLOW классификация маршрута.

  ⛔ Игнорировать месячную эмиссию потому что «в день немного».
     127M/мес × $0.026 = $3.3M/мес. За квартал $10M против TVL $170M =
     ~6% размывания в квартал. Это макро-фактор.

  ⛔ Считать «предстоящий разлок» без даты. Дата = порог MONITOR_72h.

  ⛔ Не разделять linear vesting (постоянный поток) и cliff-unlock
     (одномоментный разлок). Cliff-разлок с большим объёмом =
     событийный риск, требует отдельного MONITOR-пункта.

## MUST #18 — HOLDER CONCENTRATION operational (v5.0)

```
ИСТОЧНИК ОСНОВНОЙ:  Nansen token_current_top_holders
                    mode=spot chain=starknet tokenAddress=<STRK L2 addr>
                    или chain=ethereum tokenAddress=0xca14007...
ИСТОЧНИК FALLBACK:  Starkscan /accounts?tokenAddress=... top holders
                    web_fetch https://voyager.online/token/<addr>/#holders

ПОЛЯ НА ВЫХОД:

  top10_pct              % supply у топ-10 адресов
  top10_addresses        список 10 адресов с метками (CEX/DEX/Foundation/EOA)
  cex_pct                сумма % на CEX-hot-wallets
  foundation_pct         сумма % на Foundation/multisig
  effective_top10        top10_pct − cex_pct − foundation_pct
  top100_pct             % supply у топ-100
  gini_est               индекс Джини по топ-100
  active_top10           сколько из top10 двигались за 30 дней (nansen)
  concentration_risk     LOW | MEDIUM | HIGH по effective_top10:
                           <15%   LOW
                           15-30% MEDIUM
                           >30%   HIGH

ФОРМУЛА GINI по топ-100 (быстрый прокси):
  arr = sorted([balance for addr in top100])
  n = len(arr)
  cumsum = np.cumsum(arr)
  gini = (n + 1 - 2 * cumsum.sum() / arr.sum() / n) / n

Обычно gini 0.6-0.8 для здорового альткоина без Foundation-концентрации,
>0.85 = сильная концентрация.

СТРОКА В ОТЧЁТЕ:
  HOLDERS: top10=X% (eff Y% ex-CEX/Foundation) · top100=Z% ·
           gini=G · active=N/10 · concentration_risk=<LOW|MED|HIGH>

ЛОВУШКИ:
  ⛔ Включать CEX hot wallets как «держателей». Binance, OKX, Bybit —
     это учётные записи бирж. Внутри них — сотни тысяч реальных
     владельцев. Вычитать перед расчётом effective_top10.

  ⛔ Считать Foundation как «медведя-держателя». Foundation с
     vesting-графиком — известный риск, оценивается через MUST #17,
     не через MUST #18. Concentration_risk считается ex-Foundation.

  ⛔ Показывать только top10 без top100. Top10 может быть 40% (высокая),
     а top100 = 50% (плоское distribution дальше) — это одна картина.
     Top10 = 40%, top100 = 90% — совсем другая.

  ⛔ Не проверять активность. HIGH концентрация + active=0/10 =
     «спящий кит» (низкий риск в 72ч). HIGH + active=8/10 =
     «раздача идёт». Разница в риске.

  ⛔ Путать Foundation multisig с EOA-китом. Multisig 3/5 требует
     координации — меньшая угроза чем EOA-кит с одним ключом.
```

## MUST #19 — DEX LIQUIDITY DEPTH operational (v5.0)

```
ИСТОЧНИК ОСНОВНОЙ: DefiLlama /pools?token=STRK
                   для точности — прямые запросы:
                     Ekubo (L2)      GraphQL API
                     JediSwap (L2)   subgraph
                     Nostra (L2)     API
                     Uniswap V3 L1   subgraph (pair STRK/ETH, STRK/USDC)
ИСТОЧНИК FALLBACK: web_fetch https://defillama.com/token/starknet
                   с извлечением dex-listing

ПОЛЯ НА ВЫХОД:

  total_dex_tvl_usd      суммарная TVL STRK-пар (L1 + L2)
  active_pools_count     число пулов с TVL >$50k
  depth_2pct_bid_usd     сколько $-продаж двигает цену ↓2%
  depth_2pct_ask_usd     сколько $-покупок двигает цену ↑2%
  depth_asymmetry        bid_depth / ask_depth (>1 = легче падать)
  dex_vol_24h_usd        суточный DEX-объём STRK
  cex_vol_24h_usd        суточный CEX-объём (для сравнения)
  dex_vs_cex_ratio       dex_vol / cex_vol
  l1_l2_split            {L1: X%, L2: Y%} — где основная ликвидность
  fragility              LOW / MEDIUM / HIGH по depth_2pct_bid:
                           >$200k    LOW
                           $50-200k  MEDIUM
                           <$50k     HIGH

РАСЧЁТ DEPTH через CPMM формулу (для V2-style пулов):
  Для каждого пула с балансами (x_strk, y_usd) и текущей ценой P:
  Двинуть цену на -2% означает купить у пула STRK на:
    x_target = x_strk × sqrt(1.02)  → продать (x_target - x_strk) STRK
    usd_needed = k / x_target - y_usd   где k = x_strk * y_usd
    
  Для V3 (Uniswap V3) — использовать concentrated liquidity в range
  ±2% от текущей цены (это ключевое отличие: L может быть 0 вне range).

Суммировать depth по всем пулам с весом их TVL.

СТРОКА В ОТЧЁТЕ:
  LIQUIDITY: DEX TVL $X (L1 A% / L2 B%) · depth ±2%: bid $Y / ask $Z ·
             asym=D · dex/cex=R · fragility=<LOW|MED|HIGH>

ЛОВУШКИ:
  ⛔ Складывать TVL всех пулов как «общую ликвидность». TVL ≠ depth.
     $5M пул с концентрацией у $0.05 не даёт глубины у $0.026.
     Считать depth именно в зоне ±2% от текущей цены.

  ⛔ Не различать L1 и L2. STRK/ETH на Uniswap V3 L1 и STRK/USDC на
     Ekubo L2 — две разные книги. При падении цены могут двигаться
     несинхронно. Показывать split.

  ⛔ Путать DEX TVL со staking TVL. DefiLlama агрегирует. Staking —
     не торговая ликвидность, из расчёта depth исключить.

  ⛔ Не проверять asymmetry. Симметрия 1:1 = здоровая книга.
     Asymmetry >2 = дисбаланс: bid глубже (легче упасть, чем расти)
     или ask глубже (легче расти).

  ⛔ Игнорировать dex/cex ratio. CEX $10M vs DEX $500k = 95% price
     discovery на CEX. DEX depth важна для L2-натурных транзакций
     (staking, bridge), CEX depth — для арбитража и retail торговли.
```

  шаг 5  найти запертых: entry > mark×1.15 (лонги) / entry < mark×0.85 (шорты)
  шаг 6  сгруппировать entry_price до 0.001 → зоны breakeven-сопротивления
  шаг 7  знак фандинга × однобокость → асимметрия риска
