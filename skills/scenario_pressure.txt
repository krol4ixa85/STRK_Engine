UNLOCK PRESSURE · FILLED v0.1

INPUT (из /mnt/project/vesting_schedule_json.txt):
  · max_supply · circulating_supply
  · allocations: [Early Contributors, Team & Shareholders, Investors]
  · upcoming_unlocks (5 записей, ноя 2026 - март 2027)

ФОРМУЛА:

Для каждого upcoming unlock в окне [today, today + 180д]:

  # 1. базовое давление размера
  size_ratio = unlock_tokens / circulating_supply
  # size_ratio 1.28% ~= 1 пункт давления

  # 2. умножить на CEX_share (эмпирика 0.5 для STRK)
  effective_selling = size_ratio × 0.5

  # 3. умножить на bearish weight в зависимости от source
  # Early Contributors: 0.6 (частично долгосрочные)
  # Team & Shareholders: 0.4 (сильные stake incentives)
  # Investors: 1.0 (максимальное давление, private VC exit)

  # 4. распад с временем (unlock через 90 дней давит меньше сейчас)
  days_to_unlock = (unlock_date - today).days
  time_decay = max(0.2, 1 - days_to_unlock / 180)
  # unlock завтра = ×1.0, через 90 дней = ×0.5, через 180 дней = ×0.2

  # 5. накопить давление по всем unlock в окне
  pressure_i = -1 × size_ratio × 100 × cex_share × source_weight × time_decay

TOTAL:
  unlock_pressure_score = sum(pressure_i for all unlocks in 180d window)
  clip to [-10, 0]

STRUCTURE PRESSURE · FILLED v0.2

INPUT (из MUST #16 · skills/structure_mesto.txt):
  · current price
  · VAL / POC / VAH (свежий VP расчёт)
  · regime (5 состояний из skills/regime.txt)
  · CYCLE_BTC (UP / NEUTRAL / DOWN)
  · PHASE (B / C / D / E, включая half-weight подтипы)
  · long_liq_cluster (ближайший из HL Squeeze module)

ФОРМУЛА (4 подкомпонента):

┌────────────────────────────────────────────────────────────────┐
│ 1. POSITIONAL vs VA (где мы в комнате) · [-2 .. +1.5]         │
└────────────────────────────────────────────────────────────────┘

  if px < VAL:
      depth_pct = (VAL - px) / VAL × 100
      positional = -2.0 × min(1.0, depth_pct / 5.0)
      # клип на 5% ниже VAL для максимального penalty

  elif VAL <= px <= VAH:
      positional = 0
      # «дома» — нейтрально

  else:  # px > VAH
      height_pct = (px - VAH) / VAH × 100
      positional = +1.5 × min(1.0, height_pct / 10.0)
      # extension пейс max, клип на 10% выше VAH

Логика: чем глубже цена ниже VAL — тем сильнее bearish давление,
но клипается через 5% (иначе positional может съесть весь score).
Extension выше VAH — умеренно bullish (тренд), но с меньшим весом
чем dump ниже VAL (крипто-асимметрия downside).

┌────────────────────────────────────────────────────────────────┐
│ 2. REGIME × CYCLE_BTC (условия крипто-риска) · [-2 .. +2]     │
└────────────────────────────────────────────────────────────────┘

Матрица 5 × 3:
                       cycle=UP  cycle=NEUTRAL  cycle=DOWN
  trending_up          +2.0      +1.0            0.0
  ranging              +0.5       0.0           -0.5
  volatile             -0.5      -1.0           -1.5
  trending_down        -1.0      -1.5           -2.0
  quiet                 0.0       0.0            0.0

Логика: 
  · UP-cycle + trend up = лучший setup
  · DOWN-cycle + volatile / trending_down = худший
  · quiet = нулевой (нет контекста для ставки)

┌────────────────────────────────────────────────────────────────┐
│ 3. PHASE (позиция в сценарии внутри волны) · [-1.5 .. +1.5]   │
└────────────────────────────────────────────────────────────────┘

  B (баланс внутри VA)                       →  0
  C-bull (сжатие у VAL, потенциальный up)    →  +1.0
  C-bear (сжатие у VAH, потенциальный down)  →  -1.0
  D-up (пробой VAH + удержание)              →  +1.5
  D-down (пробой VAL + удержание)            →  -1.5
  E-up (разгон верх)                         →  +1.0
  E-down (разгон вниз)                       →  -1.0

  Half-weight для непотдвержденных:
  ?→D-up  (пробой VAH без удержания)         →  +1.0
  ?→D-down (пробой VAL без удержания)        →  -1.0

┌────────────────────────────────────────────────────────────────┐
│ 4. DISTANCE to INVALIDATION (запас до ликвидации) [-0.5..+0.5]│
└────────────────────────────────────────────────────────────────┘

  cushion = (px - long_liq_cluster) / long_liq_cluster × 100

  cushion > 15%      →  +0.5   безопасная зона
  cushion 8-15%      →   0     нейтрально
  cushion 3-8%       →  -0.25  приближение
  cushion < 3%       →  -0.5   критическое приближение

Логика: даже при bearish setup цена ДАЛЕКО от каскада — это
частичный бонус (нет форсированной распродажи в 72ч).

════════════════════════════════════════════════════════════════

TOTAL:
  structure_pressure_score = positional + regime_cycle + phase + distance
  clip to [-6, +6]

Интерпретация:
   +3 to +6    → сильное давление ВВЕРХ (structure bullish)
   +1 to +3    → давление вверх
   -1 to +1    → нейтрально
   -3 to -1    → давление вниз
